現行NAS環境も稼働が９年を超えて動きも怪しくなっていたので新調することにしました。

実は昨年の夏頃から部材は集めてたんですが、HDDだけちょっと高いなーって思ってて様子見てたらあれよあれよというまに２倍ぐらいになってしまいましたね...

SynologyのNASケースも検討したけど、高いのとHDDが限定されるのでミニPCとケースで運用してみることにしました。

日付機種備考

  • GMKtec NucBox G3 Plus (CPU: Intel N150 / MEM: 16GB / : SSD 512GB)

NASの構築

ブートメディアを作成

  1. USB メモリを ventoy で初期化
  2. OpenMediaVault 8 の ISO を ここ からダウンロードし、USB メモリに保存
  3. （Rescuezilla の ISO を ここ からダウンロードし、USB メモリに保存）

OpenMediaVault 8 をセットアップ

ウィザードに沿って進めるだけで特に問題なく終了。 １点、GMKtec NucBox G3 Plus はすでにWindowsがインストール済みなので、そこの領域を上書きする形でインストールします。

PCのセットアップでは JetKVM を使ってキーボードとモニタを使わずにセットアップしてみた。 OMVセットアップ中、KVMのウェブ画面上でモニタの接続が切れた旨、表示されることがあった。 原因は入力がなかったので画面がスリープしていただけだったので、キー入力をしたら表示された。

なぜかNICのインターフェースがONになっていなかったので、viで設定を変えてなんとかONにした。 が、どうやら omv-firstaid コマンドで設定できたようだ。

omv-firstaid コマンドについて

ヘルプで出る利用できる機能の一覧を日本語訳

  1. Configure network interface (ネットワークインターフェースの設定)
  2. Configure time zone (タイムゾーンの設定)
  3. Configure workbench (ワークベンチの設定)
  4. Change Workbench administrator password (ワークベンチ管理者パスワードの変更)
  5. Reset failed login attempt counter (ログイン失敗回数カウンターのリセット)
  6. Restore configuration backup (設定バックアップの復元)
  7. Check configuration status file (設定ステータスファイルの確認)
  8. Check RRD database (RRDデータベースの確認)
  9. Refresh APT package lists and clean caches (APTパッケージリストの更新とキャッシュのクリーンアップ)
  10. Clear local upload package repository (ローカルアップロードパッケージリポジトリのクリア)

HDD をケースに装着しPCに接続

  1. HDDを順番にトレイにねじ止めし挿入する
  2. dip スイッチ で RAID 5 に設定し、所定操作で反映。
  3. PCにケーブルを繋ぎ、電源をON
  4. OMVのウェブ画面でHDDが認識されていることを確認。DDの情報でRAID 5 となっていることを確認

OS側でソフトレイドにしないのは、パフォーマンス的なところと、PCフリーズでRAIDが壊れると困るなってところでケースのRAID機能を使うことにした。 これが吉と出るか凶と出るか...

HDD ケースのRAIDの切り替え方法は Amazonの販売ページ によると、

RAID モードの切り替え方法： 電源オフの状態でRAID紹介表を参考して、 dip スイッチを利用したい RAID モードを選定。 針の孔のリセットボタンを長押しながら、電源ボタンを 3 秒くらい押し、ハードデスクLEDインジケーターが白く点滅してRAID設定完了。リセットボタンを離します。 ディスク管理で新しいハードディスクをフォーマットします。[PC]> [ デバイスの管理 ]> に移動し、現在の RAID モードを確認します。

PM 以外のモードは、モード切り替える前に dip スイッチをPM モードに戻して、RAID モードの切り替え設定する必要があります。

となっているが... 取説と記載が違うんですよね...

RAIDモードを設定して、起動するもすぐFANが止まり、初期不良か電力不足か？と色々試してたので、結局どちらが正しいか不明。 結局、原因は付属の USB Type C ↔︎ Type C / Type A の変則的なケーブルが外れてたので、PC側が電源が切れたとHDD ケースが判断しスリープになってたからのよう。 HDD ケースはアクセスがないとスリープモードになるらしいので、NASとして運用していて支障があるなら変更予定。
